# BOONO V4.5 — exécution PM/efficiency, ticker qualifiant et timing 3m — 05/10/2026

## Décisions validées

V4.5 applique les décisions issues du cas SHORT du 05/10 au matin :

1. MCB 15m crée l'opportunité directionnelle.
2. Le 3m ouvre et ferme la fenêtre tactique d'exécution.
3. PM Live post-setup + efficiency peuvent autoriser l'entrée sans confirmation obligatoire du ticker.
4. Le ticker reste mesuré et journalisé, mais devient un qualificateur de conviction et non un portier.
5. Aucun seuil de distance prix du type 250/325 USD consommés n'est ajouté.
6. La péremption structurelle du setup est observée en shadow via OPEN -> LATE -> EXPIRED.
7. UP_REINFORCED_3M ferme une nouvelle fenêtre SHORT tardive et alerte une respiration sur un SHORT ouvert, mais ne peut jamais sortir seul la position.

## Entrée : ticker rétrogradé

Pour une position flat avec setup MCB valide :

- setup structurel valide et cohérence 3m déjà exigés par setup-lifecycle ;
- PM post-setup doit être TRANSLATING ;
- la matérialité V4.4 reste inchangée :
  - |netSinceSetup| >= 10 USD ;
  - efficiencySinceSetup >= 25 %.

Si ces conditions sont réunies :

- ENTER_LONG / ENTER_SHORT est autorisé ;
- stage = SETUP_PM_READY ;
- tickerConfirmed peut être false ;
- le statut ticker est conservé dans evidence pour qualifier la conviction.

Aucun nouveau seuil n'est inventé dans V4.5.

## UP_REINFORCED_3M

Définition :

- signal MCB natif 3m UP confirmé ;
- valeur <= -60 ;
- asymétrique ;
- actif dans son cycle natif jusqu'au prochain DN 3m confirmé ;
- aucun timer artificiel et aucune distance prix d'expiration.

Pour une candidate SHORT :

- si l'événement appartient au cycle 3m courant, le setup reçoit :
  - UP_REINFORCED_3M_CLOSES_SHORT_ENTRY_WINDOW ;
  - noNewShort = true ;
- une nouvelle entrée SHORT est donc refusée dans cette fenêtre.

Pour un SHORT déjà ouvert :

- action = HOLD ;
- stage = RESPIRATION_ALERT ;
- exitAuthority = false.

Le 3m est donc un pouvoir de timing, pas une autorité stratégique de sortie.

## Distinction 15m / 3m

Le UP_REINFORCED 15m existant reste distinct de UP_REINFORCED_3M.

V4.5 ne retire pas l'autorité déjà attribuée au signal stratégique 15m ; la modification validée porte sur le signal renforcé 3m et sur le rôle du ticker à l'entrée.

## Shadow : SETUP_OPEN -> SETUP_LATE -> SETUP_EXPIRED

Le nouveau champ setup.timingShadow est observation-only.

### SETUP_OPEN

- cohérence locale de type TURN_ALIGNED ;
- fenêtre tactique encore en phase de retournement.

### SETUP_LATE

- cohérence de type LOBE_ALIGNED ;
- l'impulsion 3m est déjà établie ;
- aucun veto n'est appliqué pour l'instant.

### SETUP_EXPIRED

- un setup précédemment armé perd sa cohérence 3m ;
- ou UP_REINFORCED_3M ferme explicitement une fenêtre SHORT.

timingShadow.decisionImpact = false.

Exception : UP_REINFORCED_3M possède son effet explicite NO_NEW_SHORT validé ; le statut LATE, lui, reste purement shadow.

Objectif : observer 5 à 10 cas avant de décider si SETUP_LATE doit devenir non tradable.
