# V4.8 — 4h capitulation guard — 2026-10-08

## Version
`v4.8-4h-capitulation-20261008`

## Principe
Adaptation de la logique "4h / 24m" à BOONO :

- 4h = permission de chercher un retournement majeur ;
- 15m = setup de retournement ;
- 3m + PM = timing / exécution.

Le 4h ne choisit jamais le prix d'entrée.

## Deep 4h capitulation
Un LONG de retournement est verrouillé lorsque :

- lobe 4h courant = CREUX ;
- le lobe a atteint LBW <= -60 ;
- structuralDirection 4h reste SHORT.

Le verrou persiste même si le LBW 4h respire ensuite au-dessus de -60, tant que la structure 4h n'a pas réellement tourné.

État :
`DEEP_4H_WAIT_UP_SUB60`

## Armement
La recherche LONG est déverrouillée uniquement par un UP natif 4h confirmé à/below -60.

Causalité explicite :
- le timestamp de la bougie est descriptif ;
- le signal devient utilisable à `availableAt = barTs + 4h`, après clôture.

Après l'armement 4h, une preuve 15m nouvelle doit apparaître après `availableAt` :
- nouveau pivot structurel 15m confirmé, ou
- nouveau signal natif 15m aligné.

État intermédiaire :
`4H_REVERSAL_ARMED_WAIT_NEW_15M`

Puis :
`4H_REVERSAL_ARMED_15M_READY`

Seulement alors 3m + PM peuvent exécuter.

## Anti-churn macro
Un même UP4h sub-60 ne peut pas financer plusieurs campagnes LONG après un échec.

Si une campagne capitulation LONG financée par un armement 4h se termine avec PNL <= 0 :
`4H_ARM_CONSUMED_AFTER_FAILED_REVERSAL`

Il faut alors :
- un nouvel armement 4h causal, ou
- un vrai retournement structurel 4h qui fait sortir le marché du régime deep-capitulation.

## Structural pivot breach
Pendant une capitulation 4h profonde, une position LONG est invalidée si le creux E15 qui soutenait son entrée est cassé simultanément par :
- prix < prix du pivot ;
- LBW15 < LBW du pivot.

Sortie :
`EXIT_STRUCTURAL_PIVOT_BREACH`

Cette sortie invalide le trajet LONG qui supportait l'exécution ; elle n'attend pas un nouveau DN/E15.

## Hard risk
Le hard cap 500 USD prix devient réellement hard :
- perte actuelle >=500, OU
- MAE observée depuis l'entrée >=500.

Une excursion intracycle >500 déclenche donc EXIT_RISK au prochain cycle même si le prix a rebondi.

## Collecte 4h
Le collecteur multi-TF écrivait déjà MA200 + wt1_cross_up/down dans les lignes 4h, mais certains CSV historiques conservaient un header legacy 12 colonnes.

`tab2-collector` migre maintenant automatiquement les headers legacy vers :
timestamp,open,high,low,close,lt_blue_wave,blue_wave,money_flow,buy,sell,dbsi_top,dbsi_bottom,ma200,wt1_cross_up,wt1_cross_dn

Aucune donnée historique n'est réécrite ; seul l'en-tête est migré.
