# BOONO V4.10.2 — Continuation Re-entry Shadow — 2026-10-15

## Objet

Mesurer, sans impact trading, si BOONO devrait parfois réentrer dans la même campagne après une sortie de protection lorsque le marché reprend réellement.

Motivation principale : après #127, BOONO est sorti correctement via EXIT_ECONOMIC_PROFIT_FLOOR, puis a raté une continuation LONG de plus de 1 000 USD alors que le ticker et PM montraient plusieurs séquences de rendement très élevé.

## Portée

Strictement shadow :
- decisionImpact: false ;
- ne crée aucune entrée ;
- ne modifie aucun veto live ;
- ne modifie aucun exit.

## Armement

Le shadow ne s'arme qu'après une sortie protectrice :
- EXIT_ECONOMIC_PROFIT_FLOOR ;
- EXIT_MFE_PROTECTION ;
- EXIT_PROFIT_PROTECTION.

Les sorties d'échec / risque / invalidation ne sont pas éligibles.

## Conditions d'une candidature de continuation

Après la sortie :
1. la thèse 15m reste dans la même direction ;
2. aucun signal 15m opposé frais n'a invalidé la campagne ;
3. un nouvel événement natif 3m dans le même sens apparaît après la sortie ;
4. le lobe 3m est dans le même sens ;
5. PM rolling 3m ET 5m traduisent dans ce sens ;
6. efficiency3m >= 25 % ;
7. une mémoire MF lente 2h/4h ne s'oppose pas à la direction.

La structuralDirection 3m n'est volontairement pas un gate dans ce shadow : l'expérience vise précisément à mesurer les continuations que WAIT_3M_15M_SYNC peut manquer après une petite crête/respiration 3m.

Le ticker ne crée jamais la direction et n'est pas un gate. Il qualifie la qualité d'effort/rendement.

## Qualification ticker

- EXTREME_YIELD : yield >= P95 ;
- LOW_EFFORT_HIGH_YIELD : yield >= P75 avec effort < P75 ;
- PRODUCTIVE_YIELD : yield >= P75 ;
- UNPRODUCTIVE sinon.

## Anti-churn

- une seule candidature maximum par sortie protectrice ;
- aucune preuve PM/ticker pré-sortie n'est réutilisable ;
- un nouvel événement 3m après sortie est obligatoire ;
- PM 3m + 5m doit être aligné ;
- la candidature est ensuite suivie en shadow avec :
  - shadowMfeUsd ;
  - shadowMaeUsd ;
  - currentSignedUsd ;
  - reachedEconomicMove (MFE >= 220) ;
  - churnRisk (MAE >= 180 avant MFE 220).
