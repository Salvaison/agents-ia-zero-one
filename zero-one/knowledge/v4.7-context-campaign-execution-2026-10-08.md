## Version

`v4.7-context-campaign-execution-20261008`

## Motivation

Audit des trades #68→#80 :
- le trajet 1h est utile comme contexte mais trop puissant lorsqu'il devient un veto d'admission ;
- plusieurs faux départs proviennent d'une bonne impulsion PM fraîche qui n'est pas soutenue par la conversion rolling 3m/5m ;
- un nouveau cycle 3m pouvait recréer une opportunité dans la même campagne 15m après un échec ;
- #78 montre qu'une exécution peut être clairement ratée sans que la thèse MCB soit encore invalidée ;
- #68/#79/#80 montrent qu'un gros MFE peut être monétisé par PM + microstructure avant un signal MCB stratégique tardif ;
- la position dans le range donne une mesure naturelle du terrain restant / R:R.

## 1. Rôle du 1h

Le 1h reste calculé par trajet causal E→E, mais il est désormais un **qualificatif de phase / risque**.

`AGAINST_BACKGROUND_NEEDS_MATURE_15M_AND_3M_TRANSITION_MEMORY` est retiré de l'admission.

Un setup valide 15m/3m peut donc être armé contre le trajet 1h.

Le setup expose :
- `backgroundQualifier = WITH_1H_WAVE | COUNTER_1H_WAVE`
- `oneHourDecisionImpact = QUALIFIER_ONLY`

Le 1h ne sert plus d'outil anti-churn.

## 2. Mémoire de campagne 15m

Une campagne est identifiée par :

`campaignKey = direction | 15mLobeStartTs`

Après un trade perdant dans une campagne, un simple nouveau cycle 3m ne suffit plus à réarmer la même campagne.

Réarmement permis si :
- la campagne 15m change ;
- ou un nouveau signal natif 15m aligné apparaît après la sortie ;
- ou l'exception `UP_REINFORCED` est active.

La mémoire ne recycle aucune preuve PM/ticker.

## 3. Continuité d'entrée adaptative

Une impulsion PM post-setup reste nécessaire mais n'est plus suffisante à elle seule.

Entrée normale :
- PM fraîche matérialisée ;
- rolling 3m doit être dans le même sens.

En `CHOP_SHADOW` / `LOW_EDGE_SHADOW` :
- rolling 3m aligné ;
- rolling 5m aligné ;
- efficacité 3m >= 37,5 % (1,5× le minimum standard de 25 %).

`UP_REINFORCED` reste une exception MCB forte.

But : distinguer un vrai changement de conversion d'un simple contre-pulse propre de 30 secondes.

## 4. EXIT_EXECUTION_FAILURE

Nouvelle sortie sans invalidation MCB requise.

Condition :
- position en perte ;
- MFE <= 25 % du mouvement économique minimum (<=55 USD prix) ;
- PM adverse persistante / productive sur 3m ;
- microstructure adverse productive.

Sens :
> l'exécution n'a jamais fonctionné ; abandonner cette entrée même si la thèse structurelle peut encore survivre.

Replay #78 :
- entrée 82 849,3 ;
- sortie réelle : 82 256,7 / ~-593 USD prix ;
- V4.7 aurait déclenché vers 05:50:43 à ~82 764,5 / ~-85 USD prix.

## 5. EXIT_MFE_PROTECTION

TP / protection du gain sans invalidation MCB.

Condition :
- MFE >= 440 USD prix (2× mouvement économique minimum) ;
- restitution >= 180 USD depuis le MFE ;
- PM adverse productive ;
- microstructure adverse productive.

Replay :
- #79 : protection vers 08:22 au lieu de rendre presque tout son MFE ;
- #80 : protection vers 10:04, après son MFE de 09:23 et avant la sortie native de 10:15.

## 6. Range / R:R

`structuralRoom.rangeRr` détecte un groupe VAH/POC/VAL et expose :
- VAL / POC / VAH ;
- hauteur du range ;
- position normalisée du prix ;
- terrain restant vers la borne cible ;
- fraction de range restante ;
- qualité `LOW_RR / TIGHT_RR / OPEN_RR` ;
- états outside range / reclaim.

Aucun veto automatique.

Exemple #74 :
- SHORT ~83 180 ;
- VAL ~82 918 ;
- ~261 USD de terrain restant ;
- ~10 % seulement de la hauteur du range → `LOW_RR`.

## Invariants conservés

- Direction = MCB uniquement.
- PM mesure conversion, ne crée jamais la direction.
- ticker qualifie rendement / effort / persistance.
- 3m n'a pas d'autorité stratégique de sortie seul.
- WHERE / niveaux / range ne choisissent jamais LONG/SHORT.
- preuves microstructurelles pré-sortie jamais recyclées.
- hard risk 500 USD reste le dernier filet de sécurité.
