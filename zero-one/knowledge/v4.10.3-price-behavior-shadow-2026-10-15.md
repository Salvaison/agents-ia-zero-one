# BOONO V4.10.3 — Price Behavior Shadow — 2026-10-15

## Principe

Le prix est étudié comme un comportement autonome de conversion et non comme une simple conséquence terminale de la thèse MCB.

Cette couche est strictement shadow :
- decisionImpact: false ;
- aucune entrée ;
- aucune sortie ;
- aucune direction créée.

Elle reste active en permanence, position ouverte ou non, setup présent ou non.

## 1. Mémoire persistante des signaux 3m / 15m

La mémoire native distingue explicitement :
- SIGNAL3_TO_SIGNAL15 ;
- SIGNAL15_TO_SIGNAL3 ;
- SIGNAL15_ONLY.

Pour la séquence stratégique courante, le dernier signal 15m est l'ancre.
Un signal 3m de même sens dans le cycle stratégique courant établit la lignée.

Point important :
un signal 3m opposé postérieur est enregistré comme opposition tactique mais ne détruit pas la mémoire stratégique de la vague.
La mémoire change réellement quand le signal 15m stratégique change.

Champs principaux :
- strategic15m ;
- precursor3m ;
- follower3m ;
- latest3m ;
- tacticalOpposition ;
- tacticalState.

## 2. Comportement effort / rendement du prix

Le shadow observe en continu le ticker brut même lorsque ticker.status = NO_THESIS.

Classes descriptives :
- EXTREME_EASY_TRAVEL : yield >= P95 avec effort < P75 ;
- EASY_TRAVEL : yield >= P75 avec effort < P75 ;
- EXTREME_PRODUCTIVE_TRAVEL : yield >= P95 ;
- PRODUCTIVE_TRAVEL : yield >= P75 ;
- HIGH_EFFORT_LOW_YIELD : effort >= P75 avec yield < P75 ;
- LOW_YIELD ;
- UNKNOWN.

Mesures conservées :
- yieldVsP75 / yieldVsP95 ;
- effortVsP75 ;
- cadence ;
- flow BTC/s ;
- yield USD/BTC ;
- easeRatio = yieldVsP75 / effortVsP75.

## 3. PM multi-horizon

La même observation conserve :
- net1m ;
- net3m ;
- net5m ;
- efficiency1m / 3m / 5m ;
- direction 3m ;
- direction 5m ;
- direction multi-horizon quand 3m et 5m sont cohérents.

## 4. Relation prix / mémoire de vague

Le shadow qualifie :
- WITH_SIGNAL_MEMORY ;
- AGAINST_SIGNAL_MEMORY ;
- NO_RELATION.

Et distingue :
- INTERESTING_PRICE_WITH_WAVE ;
- INTERESTING_PRICE ;
- OBSERVING_PRICE.

Une vague établie + prix facile/productif dans le même sens est donc observable même si l'admission live reste bloquée.

## 5. Persistance des épisodes

Chaque épisode homogène conserve :
- startedAt ;
- startPrice ;
- durationMinutes ;
- samples ;
- currentSignedMoveUsd ;
- maxFavorableUsd ;
- maxAdverseUsd.

L'objectif est d'étudier empiriquement la durée et l'amplitude des régimes où le prix se déplace facilement.
