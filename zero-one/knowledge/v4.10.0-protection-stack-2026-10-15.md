# BOONO V4.10.0 — Protection Stack — 2026-10-15

## Motivation
Le trade #125 a exposé trois faiblesses distinctes :
1. une entrée LONG encore admise alors que le 3m était déjà très avancé dans sa crête ;
2. un gagnant ayant atteint MFE +267.2 USD transformé en forte perte ;

## 1. SETUP_LATE devient actif
L'ancien timing shadow était trop large : il classait beaucoup de setups structurellement alignés comme tardifs.

La version active utilise une géométrie 3m plus stricte :
- lobe 3m dans le sens du candidat ;
- âge du lobe >= 12 minutes (4 bougies 3m) ;
- recovery <= 12 %, donc lobe toujours EXTENDING / proche de son extrême.

Quand ces conditions sont réunies :
- état : SETUP_LATE ;
- decisionImpact : CLOSES_NEW_ENTRY_WINDOW ;
- raison : SETUP_LATE_CLOSES_ENTRY_WINDOW ;
- aucune nouvelle entrée n'est autorisée sur ce setup.

Une fois late, le même setup ne se réouvre pas.

Le replay de #125 donne :
- âge 3m : 14.18 min ;
- recovery : 0 ;
- direction lobe : LONG ;
- candidat : LONG ;
=> entrée refusée.

## 2. Plancher économique 220 -> 180 actif
Mécanisme distinct de la gestion des gros winners 440/180.

Règle :
- MFE >= 220 USD arme le plancher ;
- si currentSignedUsd revient à <= +180 USD :
  EXIT_ECONOMIC_PROFIT_FLOOR.

Aucune confirmation PM/ticker/MCB n'est nécessaire : il s'agit de protéger la viabilité économique déjà acquise.

#125 :

- aurait donc armé le plancher ;
- le retour à +180 aurait fermé bien avant la perte finale.

Le mécanisme 440/180 reste en place pour la logique stress TP / runner et n'est pas remplacé.

## 3. Bypass LIVE 15m de protection
Un signal LIVE 15m opposé n'a toujours aucune autorité seul.

Mais le stack suivant devient une autorité de sortie :
- signal natif 15m LIVE opposé ;
- structure causale 3m opposée ;
- PM adverse productif ;
- MA200 3m perdue ou rejetée après l'entrée.

Quand les quatre sont présents :
EXIT_LIVE_SIGNAL_STACK_PROTECTION

Ce stack bypass l'attente de la clôture 15m.

Le ticker n'est pas requis.

### PM adverse productif
Réutilise la matérialité existante de la conversion prix :
- net3m dans le sens opposé ;
- |net3m| >= 10 USD ;
- efficiency3m >= 25 %.

### MA200
La MA200 utilisée est la MA200 3m, cohérente avec le timing.
La preuve exige :
- prix actuellement du mauvais côté de la MA pour la position ;
- ET perte/croisement ou rejet de la MA après l'entrée.

Ce n'est donc pas un simple filtre de position sous/au-dessus de MA.
